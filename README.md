# Найди 5 отличий

Браузерная игра: 3 уровня, на каждом две почти одинаковые картинки и 5 отличий.
Чистый HTML/CSS/JS, без сборки и библиотек.

## Уровни
1. **Маркет скинов**: фото монитора с маркетом CS
2. **Энергетики**: полка в магазине
3. **Скины Fortnite**: коллекция скинов

Отличия сделаны редактированием фото: перекраска предметов, удаление, замена одной банки другой, стёртая подпись, зеркальное отражение.

## Что есть
- 3 уровня по 5 отличий, кружок на обеих картинках, счётчик «Найдено: N из 5»
- Промах: красный крестик, вспышка, тряска и **+5 сек**
- Таймер на каждый уровень
- Экран результата: общее время и количество промахов
- Кнопка «Поделиться» копирует текст с результатом и ссылкой на игру
- На телефоне картинки одна над другой и обе влезают в экран, зона попадания под палец
- Дополнительно: подсказка 💡 (+15 сек), рекорд сохраняется, звук и анимация при находке

## Файлы
| Файл | Что это |
|---|---|
| `index.html`, `style.css`, `game.js` | игра |
| `levels.js` | картинки уровней и координаты отличий |
| `images/` | `levelN-a.jpg` (оригинал) и `levelN-b.jpg` (с отличиями) |

## Публикация
**GitHub:** создай пустой репозиторий на github.com, затем в папке проекта выполни:
```
git init
git add .
git commit -m "Найди 5 отличий"
git branch -M main
git remote add origin https://github.com/ЛОГИН/spot-the-difference.git
git push -u origin main
```
**Netlify:** app.netlify.com → Add new site → Import an existing project → GitHub → выбери репозиторий.
Build command оставь пустым, publish directory: `.`. Нажми Deploy.
